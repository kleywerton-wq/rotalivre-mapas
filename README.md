# Mapas offline do RotaLivre

Repositório **público apenas para distribuição dos dados de mapas**, separado do código privado do aplicativo.

- `catalogo.json`: lista de regiões disponíveis para baixar pelo próprio aplicativo RotaLivre.
- **GitHub Releases**: arquivos dos mapas e do roteamento (publicados apenas depois de validação e revisão de licenças).
- O usuário baixa e instala os pacotes **dentro do aplicativo**, sem abrir o navegador ou o site GitHub.

**Situação atual:** o catálogo possui zero regiões; nenhum mapa regional está publicado. O RotaLivre continua funcionando com mapa online enquanto nenhuma região offline for instalada e ativada.

A inclusão de pacotes exige cobertura validada, fontes com permissão de redistribuição, SHA-256 verificado e testes de download e navegação Android. O repositório não contém planilhas, rotas pessoais ou informações de usuários.
